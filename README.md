# Codex Wallpaper

Windows 10/11 x64 便携壁纸选择器。将本机 Wallpaper Engine 的壁纸作为 Codex / ChatGPT 桌面客户端的窗口背景。无需管理员权限，无需安装 Python、Node.js 或 .NET SDK，使用 Windows 自带的 .NET Framework 4.8。

这是社区独立项目，与 OpenAI、Valve 或 Wallpaper Engine 无隶属关系。

**[下载便携版](https://github.com/ChangJiang326/codex-wallpaper/releases)** · [验证范围](TESTING.md) · [MIT 许可证](LICENSE)

## 使用

1. 将 `CodexWallpaper-1.2.1-win-x64.zip` 解压到一个长期保留的目录，保留 `media` 文件夹。
2. 这台电脑需要已安装 Wallpaper Engine 和 Codex / ChatGPT 客户端。
3. 双击 `CodexWallpaper.exe`。程序自动查找 Steam 安装位置、Steam 多库目录和本地壁纸。
4. 选择壁纸与动画开关，保留 **GPT / Codex 启动后自动应用**、**随 Windows 登录在后台启动**，点击一次 **保存并应用（以后自动）**。
5. 调整壁纸可见度。默认 24%；数值越高，壁纸越明显、文字越淡。
6. 之后直接从原来的 GPT / Codex 图标启动，软件自动接入保存的壁纸。点设置窗口的 **×** 或最小化会收进托盘；双击 EXE 或托盘图标可再次打开设置。

## 设置一次，自动生效（v1.2）

v1.2.1 修复了冷启动焦点切换时跳过动画、动画被后续激活的客户端覆盖等问题，并减少静止窗口的重复合成操作。首次检测到后台窗口时最多等待 10 秒移交焦点，再自动应用；持续留在后台的窗口不播放动画、不抢焦点。

- 后台进程约每 0.5 秒检查客户端窗口。Windows 登录启动使用当前用户的 `HKCU/Software/Microsoft/Windows/CurrentVersion/Run` 中独立的 `CodexWallpaper` 项，命令为本程序路径加 `--background`。不要求管理员权限，不改 GPT 快捷方式。
- 登录后不弹设置窗口、不自动打开 GPT、不扫描整套壁纸库。检测到客户端出现后才读取已保存的那张壁纸；引擎未运行时尝试启动已配置的 Wallpaper Engine。
- 点击“保存并应用”会先保存配置，即使客户端启动失败也无需重新选壁纸。首次未保存过壁纸时，后台不会随意选择封面列表中的第一张。
- 已开启动画时，只在新窗口位于前台时自动播放一次；后台接入不抢焦点，最小化/恢复和切换焦点不重复播放。关闭动画后直接接入壁纸。
- **恢复原样 / Ctrl+Alt+F10** 暂停本次窗口的自动应用；真正关闭并重新创建客户端窗口或重启客户端后，会重新接入。只隐藏到托盘后再显示的同一个窗口仍保持暂停。也可在设置里再次点“保存并应用”立即恢复壁纸。
- 托盘菜单 **退出并恢复** 才会彻底结束后台进程。取消“随 Windows 登录在后台启动”可移除本软件的登录项，取消“启动后自动应用”可停止自动接入。
- EXE 必须留在保存时的目录中。升级或搬目录后，运行新位置的 EXE（先退出旧版），已保存配置会复用，登录项会指向新位置。复制到别人的电脑仍需要首次配置对方的壁纸。
- 出错会间隔 10 秒重试，每个窗口最多 3 次，之后托盘提示；修复配置后重新保存或重启客户端即可重试。
- 自动检测在窗口出现之后进行，不能保证客户端第一帧就已经有壁纸。当前仍一次接入一个主窗口。电脑实际重启、各类第三方客户端安装方式和不同启动速度的效果需要实机确认。

命令行：`CodexWallpaper.exe --background` 静默常驻；`--restore` 通知已运行的进程恢复原样；`--exit` 通知它彻底退出。普通双击会唤回已有设置窗口，不会创建第二份后台进程。

找不到引擎时，点“选择程序”选择 `wallpaper64.exe` 或 `wallpaper32.exe`。找不到壁纸时，点“添加壁纸目录”，选择 `steamapps/workshop/content/431960`、`projects/myprojects` 或一张壁纸的目录。它们必须已经下载到这台电脑。软件不复制、下载或分发壁纸。

## 龙娘启动动画（v1.1）

- 已集成 [Dragon Codex Boot](https://github.com/yushua0808-cpu/dragon-codex-boot) 的完整约 14 秒示例动画，原音轨以 25% 音量播放。来源、MIT 软件许可和媒体许可说明见 [第三方说明](THIRD_PARTY_NOTICES.md)。
- **启用启动动画** 的选择会记住。取消勾选则直接启动 / 应用壁纸；**预览**只播放动画，不启动 Codex、不改变壁纸。
- 动画与客户端/壁纸准备同时进行；未就绪时在 11.3 秒附近等待。正常末段在 12.7–13.65 秒原位交叉淡出，显示已经合成壁纸的真实客户端。保留原客户端位置与尺寸，横竖比例不同仍等比显示动画。
- `Esc` 或“跳过动画”提前进入；如果客户端或壁纸还没准备好，会等准备结束再交接。`Ctrl+Alt+F10` 可取消整个启动流程并恢复原样。
- 视频缺失、媒体组件失败或播放卡住时跳过动画；客户端等待超时会回到选择器并显示错误。运行时需要 Windows 的 H.264/AAC 媒体支持，Windows N 等缺少媒体组件的系统可能不能播放。
- 成功进入后，选择器留在系统托盘。双击托盘图标可继续选壁纸，托盘“退出并恢复”会恢复客户端外观。
- 动画可由手动应用或新客户端窗口自动触发。不扫描或替换其他快捷方式、不改写 Codex 应用包。
- 就绪判断依据窗口可响应且稳定、壁纸窗口出现及短暂预热；没有使用 Codex 官方内容加载完成事件，慢磁盘或复杂壁纸仍可能较晚显示完整内容。

## 显示方式与限制

- **完整显示**：等比留边，不拉伸；**铺满窗口**：等比裁切，不拉伸。
- 视频优先读取 Windows 媒体元数据中的原始宽高；不支持该视频格式时，以及 scene/web 壁纸，自动比例按预览图推断。有些创作者上传的是裁切封面，此时需手动选择真实比例。scene 壁纸由引擎按这个比例渲染，并非提取封面当作动态背景。
- 支持扫描 `scene`、`video`、`web` 项目，由 Wallpaper Engine 自身渲染。具体壁纸、插件、音频、交互兼容性仍取决于引擎；不加载 application 可执行程序类型的壁纸。
- 这是 Windows 窗口合成兼容模式：专用壁纸窗被放在客户端后面，客户端整体半透明。**文字、图片和按钮也会一起变淡，无法做到只透明背景、文字完全不变。** 不修改或注入 Codex 安装文件，也不要求调试端口。
- 不会切换桌面壁纸；专用壁纸可能播放它自己的音频，音频设置由 Wallpaper Engine 管理。不会发送影响全部桌面壁纸的全局暂停或静音命令。
- 壁纸由独立的屏幕外引擎窗口渲染，通过 Windows DWM 实时合成，跟随选中的一个客户端窗口。最小化/切换虚拟桌面时隐藏背景，恢复时继续显示。程序每约 80ms 同步窗口位置。
- 引擎的“其他应用最大化/全屏时暂停或停止”设置可能冻结壁纸。遇到冻结，请在 Wallpaper Engine 中检查性能/应用规则。本工具不改这些全局设置。
- 目标为普通 Windows 10/11 x64 桌面会话；远程桌面、显卡驱动、不同客户端版本可能影响 DWM 和透明窗口。ARM 原生、macOS、Linux 未支持。
- Windows 已禁用或删除 .NET Framework 4.8 的精简系统需要先恢复该系统组件。

## 恢复与本地数据

程序自带独立恢复进程：主界面崩溃或被结束时，恢复客户端透明度并关闭本工具打开的壁纸窗口。下次启动还会检查残留恢复记录。恢复前校验窗口所属进程和启动时间，避免误改重用的句柄。

若热键被其他软件占用，使用界面或托盘中的“恢复原样”。彻底退出程序会自动恢复；全部进程被强行结束时，重新启动选择器即可恢复。也可执行 `CodexWallpaper.exe --restore`。重启 Codex 本身也会重置临时透明度；后台常驻时会再按保存配置接入。

设置和诊断日志仅保存在 `%LOCALAPPDATA%/CodexWallpaper`，不联网、不上传。路径按每台电脑自动检测，不包含开发机器的固定盘符。复制软件后需要在新电脑重新选择自己的壁纸。EXE 未做商业代码签名。

## 源码与构建

在 Windows PowerShell 中运行 `./build.ps1`。编译器为系统自带的 .NET Framework C# 编译器，产物位于 `dist/CodexWallpaper-1.2.1`。开发源码采用 C# 5，界面使用 WinForms/WPF，无第三方运行库。

运行 `./tests/run.ps1` 检查库扫描、损坏项目、目录边界、等比布局、Windows 参数引用及本机 DWM/透明度恢复。
运行 `./tests/startup.ps1` 检查动画状态与开关迁移；`./tests/startup.ps1 -Live` 在测试窗口验证实际媒体播放、模拟准备延迟和淡出（约 30 秒）。这些实机测试要求可用的交互式 Windows 桌面。
运行 `./tests/regression.ps1` 检查焦点交接、静止窗口重复操作、移动及最小化恢复。
运行 `./tests/background.ps1` 检查自动接入、窗口身份、重试、暂停、设置迁移、隔离注册表登录项及实例间通信。
